# 11io

Personal website and portfolio for Ricardo Jorge, an AI Product Engineer.

The current Next.js app lives in [`v0/www/`](v0/www/). Its content covers
Ricardo's background, services, skills, projects, career, and contact details.
The site copy and links are kept in [`v0/www/lib/site.ts`](v0/www/lib/site.ts),
while the page layout is in [`v0/www/app/page.tsx`](v0/www/app/page.tsx).
Branding assets are kept in [`v0/branding/`](v0/branding/).

## Local development

The app requires Node.js and npm. From the repository root:

```bash
cd v0/www
npm install
npm run dev
```

Then open the local URL printed by Next.js.

See [`v0/www/README.md`](v0/www/README.md) for the app's commands and editing
notes.
