# 11io

Personal website and portfolio for Ricardo Jorge, an AI Product Engineer.

The Next.js app lives in [`www/`](www/). Its content covers Ricardo's background,
services, skills, projects, career, and contact details. The site copy and links
are kept in [`www/lib/site.ts`](www/lib/site.ts), while the page layout is in
[`www/app/page.tsx`](www/app/page.tsx).

## Local development

The app requires Node.js and npm. From the repository root:

```bash
cd www
npm install
npm run dev
```

Then open the local URL printed by Next.js.

See [`www/README.md`](www/README.md) for the app's commands and editing notes.
